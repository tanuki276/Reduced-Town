# Stage 1 仕様 — 街と、運転できる車1台

## 目的

「歩行シム」と「GTA-like」の境界は、車に乗れるかどうかで決まる。Stage 1 はその境界を越えることだけに集中する。交通・歩行者・警察・ミッションは入れない。

## 成果物

1. グリッド状の街区を持つ固定レイアウトの街（道路、交差点、歩道、建物、街灯）
2. 三人称で歩けるプレイヤー（歩行・ダッシュ・ジャンプ、スプリングアーム式カメラ）
3. 運転できる車1台（近づいて乗る、運転する、降りる。アーケード寄りの車両挙動）
4. Android タッチ操作（徒歩：左スティック＋右ドラッグ視点。運転：アクセル／ブレーキ／ハンドルのタッチUI）と PC キーボード操作の両対応
5. GitHub Actions で arm64 デバッグ APK を自動ビルド

## 街

- 道路グリッド：直交する道路で区切られた街区。まず 5×5 街区程度から始める（Tokyo Walk 3D の約116m四方と同規模でよい。広さより密度）
- 建物・街灯・信号・小物は CC0 アセット（KayKit City Builder Bits、Kenney City Kit 等）を実形状で配置する。ボックスの仮置きで済ませない
- 建物にはコリジョンを付ける。車も建物にぶつかる
- 交差点は見通しを確保し、中央にランドマーク的な交差点を1つ置く

## プレイヤー（徒歩）

- 三人称。移動速度・加減速・ジャンプは Small-World の PlayerController の数値を初期値とする（歩行 6.2 / ダッシュ 9.5 m/s、ジャンプ 6.5、重力 18.5）
- カメラはスプリングアーム式で、地形・建物へのめり込みを避ける
- 歩行アニメーション（歩く／走る／待機）を付ける。滑るように移動する状態で Stage 1 を完了としない

## 車

- 1台だけスポーンさせる。プレイヤーが近づいてインタラクトすると運転席に切り替わり、カメラは車追従に変わる。降りると徒歩に戻る
- 挙動はアーケード寄り：前進・後退・ステアリング・ブレーキ。ドリフトは不要
- Godot の VehicleBody3D を使うか、簡易な自前モデルにするかは実装時に決める。判定基準は「低速でも高速でも壁にめり込まず、交差点を曲がれること」
- 建物・街灯などとの衝突で止まる。プレイヤーが徒歩で車に当たってもめり込まない

## 操作

- Android：徒歩時は左仮想スティック＋右ドラッグ視点＋乗降ボタン。運転時はアクセル／ブレーキボタン＋ハンドル（スティック流用可）
- PC：WASD 移動、マウス視点、F キーで乗降、運転時は WASD

## 完了条件

- [ ] APK が実機で起動し、街を歩ける
- [ ] 車に乗って街区を1周運転し、降りて歩行に戻れる
- [ ] 歩行アニメーションが再生され、滑っていない
- [ ] 建物に徒歩でも車でもめり込まない
- [ ] CI で APK が自動ビルドされる

## Stage 1 でやらないこと

- 交通（他車の走行）、歩行者、警察・手配度、ミッション、昼夜、ラジオ、セーブ
- 複数台の車、車種の追加
- 街の拡張（Stage 2 以降に必要になったら広げる）
